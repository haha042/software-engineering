# D06 跨平台与浏览器回归

执行日期 2026-11-25。业务代码基线 `a4113ed`，macOS 27.0 arm64，Node.js v26.0.0，Chrome 158.0.8127.37。浏览器回归使用独立内存 SQLite、虚构数据和本地回环 HTTP。

| 环境 | 结果 | 覆盖 |
|---|---|---|
| macOS Node.js | 11 项通过 | 账号与权限、认证、订单、咨询、商品、通知失败补投、备份轮替及独立恢复 |
| macOS 无头 Chrome，1280×720 | 通过 | 市场搜索、管理员登录、工作台进入统计、日周切换、页面无横向溢出 |
| macOS 无头 Chrome，1440×900 | 通过 | 同上 |
| macOS 无头 Chrome，390×844 移动视口 | 通过 | 同上 |
| Windows Node.js | 待执行 | 仓库已有 Windows CI job，本分支尚未取得对应运行结果 |
| Edge、手机实机 | 待执行 | 尚无对应浏览器或设备运行结果 |
| SVG 图示、其他页面流程 | 待执行 | 待逐张检查及补充浏览器端业务流程 |

在业务系统目录执行 `npm test` 复跑 Node.js 套件。执行 `node scripts/verify-browser.js "<Chrome 可执行文件路径>"` 复跑三种视口的检查。macOS 终端及 Windows PowerShell 调用示例如下，Windows 命令需替换为本机实际安装路径。

```sh
node scripts/verify-browser.js "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

```powershell
node scripts/verify-browser.js "$env:ProgramFiles\Google\Chrome\Application\chrome.exe"
```

权限、失败和恢复证据见 [HTTP 回归测试](../test/api.test.js)、[统计授权与性能验证](../scripts/verify-statistics.js) 和 [独立恢复测试](../test/backups.test.js)。VT 状态维护在 [验收证据索引](验收证据索引-D02.md)。
