## 二、ADR 清单（模板 B）

### ADR-001 / 保持原生 HTML/CSS/JS + Node.js + SQLite

- **状态**：提议（`main` 已如此实现，但未经团队以 ADR 形式接受）
- **背景**：`AGENTS.md` 约束技术栈；团队跨 macOS/Windows。
- **比较**：A 现栈零新增依赖、跨端易跑；B 引入框架/ORM 增加构建与双端验证成本。
- **决定**：拟采用 A，明确不引入 B。
- **理由**：契合课程范围与现有 18 个自动化测试。
- **代价**：无 ORM，SQL 与迁移需手写；前端为模块脚本而非组件框架。
- **验证**：`node --test` 双端分别跑；本次仅 Windows 18/18。
- **确认**：未指派 / 未指派 / 未确认。
- **重新评估条件**：技术栈变更由用户决定时。
- **替代关系**：无。
