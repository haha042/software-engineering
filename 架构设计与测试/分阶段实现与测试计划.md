## 4. 回归与证据要求

- 每次合并前跑 `npm test`（= `node --test test/*.test.js`），记录 Node 版本、平台、原始输出路径。
- 并发不变量用**文件型 SQLite 多连接**验证，禁止用内存 Mock 或顺序调用冒充并发证据。
- 性能阈值先固定再测；失败/超时样本计入样本，不剔除不利数据。
- macOS 与 Windows 分别登记；只在某端跑过就只写该端，不扩写双平台。
- 测试失败先判责：实现不符修实现；预期错误须有依据并人工批准后才改测试；需求冲突重开 Q。禁止为全绿删断言或硬编码返回值。
